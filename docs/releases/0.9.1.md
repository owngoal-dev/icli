- `svc kickstart LABEL` and `kickstartService(_:kill:)` start a loaded launchd job immediately. `--kill` (`-k`) replaces a running instance with the executable now on disk and returns its new PID. Without it the existing process is left running and reported as `unchanged`, including on iOS 27 where launchd returns success rather than `EALREADY`.
- Kickstart requires root and the host executable's `com.apple.private.xpc.service-attach` entitlement. The CLI now carries it; service-configure alone was refused with status 144 on iOS 27. A library consumer must add it to its own signing profile if it uses this API. The denial message names the correct privilege.
- Device regression now tests two observable daemon versions across an atomic executable replacement, the returned PID, an unchanged running job, invalid and missing labels, and refusal as mobile. The TestHost supports iPad natively and registers through icli instead of iOS 27's failing uicache; the independent OCR check waits for TestHost's result.
- JP01 and JP02, both on 27.0.1 with RootHide: 55/55 non-reboot device cases, the versioned library consumer and the long-lived host checks passed on each. Irisin's daemon/helper path completed its own update, upgraded icli from 0.9.0 to 0.9.1, then installed and removed another package.
