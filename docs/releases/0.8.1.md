- icli runs on iOS 15. 0.8.0 strongly imported `xpc_user_sessions_get_foreground_uid`, an iOS 16 libxpc export, and targeted iOS 16, so every binary linking IcliKit stopped in dyld before `main` on iOS 15. The packages now require `firmware (>= 15.0)`. On iOS 15 the launchd commands read the system domain only, since there is no user domain to resolve; `print-disabled` accepts iOS 15's `true` for a disabled service; `device devmode` reports Developer Mode as enabled, not armed and not writable; and `device reboot` reports `ENOSYS` where `reboot3` is missing. `verify-binary.py` now rejects a strong import beyond the iOS 15 floor. Tested on an iPhone SE running iOS 15.8.6 with Dopamine (rootless) and on an iOS 26.6.2 vphone with RootHide.
- `screen ocr`, `screen describe` and the self-test no longer crash on iOS 15 when icli is started over SSH. Such a process has no Metal device, and Vision fell back to an OpenGL context that crashed; icli now reports text recognition as `unavailable`. The self-test skips OCR instead of failing it on a device without text recognition.
- `location get` no longer aborts on iOS 15, which lacks `initWithEffectiveBundlePath:`; icli uses the bundle form there. With Location Services turned off, `location set` fails at once instead of after about 1.6 s.
- `button wake` dismisses the lock screen of a device without a passcode in one call. From a blank screen SpringBoard spent the only Home press on waking, so the lock screen stayed up. On a device that is already awake and unlocked, `button wake` no longer sends the front app home. The result reports `locked` and `screen_off`.
- `device brightness set` on a display without an adjustable backlight, such as a vphone's, says so instead of reporting that the level was not applied.
- `screen describe` reports an element query error with its code and message.
- The acceptance runner works when it logs in as root on a rootless device: checks that must fail without privileges run as mobile, `account_password` proves the password before changing it and can no longer leave mobile with an unknown one, and `userspace_reboot` can no longer restart the device by running as root. It also accepts Dopamine's preference locations, small screens, stock DES password hashes, and devices without a backlight or Location Services, cleans up what it stages on the device, and keeps a failed wake from locking out later cases. The host soak and package consumer build from a git worktree.
