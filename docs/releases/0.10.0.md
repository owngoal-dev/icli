- icli runs on tvOS 15 and later. `make tvos` builds a separate tvOS executable from the same sources; releases publish it as a rootful `appletvos-arm64` DEB, Procursus' tvOS target, and as the bare `icli-tvos` for a system without a bootstrap or `dpkg`. The Swift Package declares a tvOS 15 floor: `IcliSystem` and `IcliLaunch` build for tvOS as they are, and `IcliKit` builds against the IOKit stub that `scripts/tvos-iokit-stub.sh` makes, because the AppleTVOS SDK leaves IOKit out. iOS code paths are unchanged.
- On tvOS, PineBoard is the system shell: `app frontmost`, `app launch` and `sb respring` work with it. A launch PineBoard refuses says why, such as Setup Assistant still running. URLs open through FrontBoard. `app register`, `app refresh` and `sb uicache` register bootstrap apps as user apps, because PineBoard disables a system app tvOS did not provision. `app frontmost` reports `com.apple.IdleScreen` while the screen saver runs, and `button wake` dismisses it. Touch, pointer, `ui tap`, clipboard, `rotation set`, `rotation lock set` and `app network` return `unavailable`, and the error for a touch names the remote's `input hid` usages to use instead.
- `icli probe` runs a JavaScriptCore script in the icli process: Objective-C classes through a reflection bridge, `console`, `fs`, `sleep`, and `api()` into a read-only set of icli's capabilities. `-e`, a file or `-` prints one JSON line `{ok, result | error, output}`, and `probe repl` is interactive. It runs inline and has no `--detach`; a caller that needs isolation spawns `icli probe` itself. JavaScriptCore is loaded at runtime, so the binary still launches no process and links no new framework.
- IcliKit exposes the probe as `evaluateProbe(_:api:)`, `runProbeREPL(api:)`, `defaultProbeAPI`, `ProbeResult`, `ProbeAPIHandler` and `ProbeAPIError`. A host passes its own `api()` handler, and `ProbeAPIError` keeps the host's error codes. All new symbols carry the `IcliProbe` or `icli_probe_` prefix.
- The `account_password` acceptance case no longer needs OpenSSL on the test Mac. The stored hash is checked for the sha512-crypt format and the reported salt, and a new host test, `scripts/test-sha512-crypt.sh`, checks `account set-password`'s hashing against published known answers.
